Azure AI cost control

Three views of Azure spend and AI telemetry, one per audience.

Spend and telemetry are not attached yet. The Savings tab is filled from the July 2026 recommendations workbook. The other three tabs are wired to their sources and fill the moment a file has rows. Nothing here is a sample or a placeholder number.

The cost panels want the output of scripts/ea_export_aggregate.py run against the EA detail export. The token, PTU, cache and error panels want Azure Monitor telemetry, which no cost export contains at any grain — see docs/03-ai-telemetry-ingestion.md.
