# Azure, August 2026

> **Correction, after the operational deck arrived.** An earlier version of this file
> reported Azure up 21.2% with Databricks jumping from $0 to $30,183 and calling that
> 76% of the increase. **That was wrong**, and the error is worth recording because it
> is easy to repeat: the enrollment export reports Databricks DBU at list price in
> `ExtendedCost`, while the deck reports it at **invoice**, which is $0 because it draws
> against the April pre-purchase. Comparing an export-basis August against a deck-basis
> July manufactured a $30K jump that does not exist. On a like-for-like basis **Azure
> fell 3.6%**. The deck was right; the comparison was not.

Sources: `Detail_Enrollment_51378402_202608_en.csv` (1,101,228 line items, aggregated
locally) and `Cloud_FinOps_Harel_August_26.pptx`, the operational monthly deck, which
already carries August on the reporting basis the CIO deck uses.

## Consumption basis, for reference

The local aggregation of the raw export gives **$226,481** for August. It reconciles
to the deck as:

| | |
|---|---:|
| Export total (consumption basis) | $226,481 |
| less Marketplace / SaaS | −$4,889 |
| less Databricks drawdown (bills at $0) | −$30,183 |
| | **$191,410** |
| Deck figure | $180,241 |
| **Unexplained residual** | **+$11,169** |

The residual is almost entirely Virtual Machines — $54,790 in the export against
$44,488 in the deck. The likely cause is reservation and savings-plan amortisation
applied in the deck's pipeline but not in the raw meter lines. **Not resolved**, and
worth settling before either number is quoted as authoritative.

Databricks consumption itself continued normally: about $29.6K/month May–July,
$30,183 in August. Utilisation of the $504,000 commitment is tracking as slide 23
describes. The new `Premium Anthropic Serverless Inference DBU` meter at $2,098 is
genuinely new — AI inference is now running inside Databricks as well.
