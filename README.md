# Finops

Tools for cloud financial operations (FinOps): cost analysis, optimization,
budgeting, and chargeback/showback reporting for AWS.

- [`.claude/skills/finops/SKILL.md`](.claude/skills/finops/SKILL.md) — a
  Claude Code skill covering cost analysis and optimization across AWS,
  Azure, and GCP.
- [`app/`](app/) — a local Streamlit dashboard: upload an AWS Cost and Usage
  Report (CUR), get spend dashboards, and (optionally, with an Anthropic API
  key) AI-generated cost recommendations and a chat interface over your data.
  See [`app/README.md`](app/README.md) to run it.
